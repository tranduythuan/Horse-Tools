Fonts bundled with Horse Tools
==============================

font/webfonts/  +  font/css/all.css
    Font Awesome 6 FREE. Icons: CC BY 4.0. Fonts: SIL OFL 1.1. Code: MIT.
    See LICENSE.txt. Free is redistributable; the Pro edition is NOT and must
    never be shipped here.

font/watermark.ttf
    Tinos Bold, by Steve Matteson. A metric-compatible, freely redistributable
    stand-in for Times New Roman, obtained from the google/fonts project.
    Used only to render the optional text watermark on uploaded images.
    Replaces the original font/logo.ttf, which was Microsoft/Monotype
    "Times New Roman" — a proprietary Windows font that may not be
    redistributed in a plugin.
