Fonts and icons bundled with Horse Tools
========================================

link/tabler/  (tabler-icons.css + fonts/tabler-icons.woff2)
    Tabler Icons 3.24.0 — MIT licence. The plugin's own admin interface icons.
    Freely redistributable.

font/webfonts/  +  font/css/all.css  +  font/LICENSE.txt
    Font Awesome 6 FREE. Icons CC BY 4.0, fonts SIL OFL 1.1, code MIT.
    Loaded ONLY by the optional "Enable Font Awesome" front-end feature, so the
    site owner can use FA icons in their own content. The Pro edition was
    removed in 1.1.0 — it is proprietary and must never be shipped here.

font/watermark.ttf
    Tinos Bold (Steve Matteson) — a redistributable, metric-compatible stand-in
    for Times New Roman, from the google/fonts project. Renders the optional
    image text watermark. Replaced the original font/logo.ttf, which was
    Microsoft/Monotype "Times New Roman" and could not be redistributed.
